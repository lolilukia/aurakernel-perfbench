08 / METHODOLOGY

How PerfBench works

A transparent view of the optimization loop and scoring contract.

  1. 01
    Write

    The model receives an operator specification and authors AscendC.

  2. 02
    Compile

    Compiler diagnostics return to the agent loop.

  3. 03
    Verify

    Functional and numerical tests gate profiling.

  4. 04
    Profile

    Real Ascend hardware reports task duration and unit counters.

  5. 05
    Optimize

    The agent edits until improvement stalls or the round budget ends.

PerfScore

Weighted blend of correctness, performance gain and cost efficiency. The exact weighting remains a benchmark-owner decision and is intentionally not invented in this prototype.
